sdcc-wasm

SDCC 4.5.0 (mcs51 port) built for WebAssembly, distributed under its own GNU General Public License, version 2 or later.

This site exists so that applications which are not GPL can fetch this toolchain at the user's request, instead of carrying GPL code inside their own distribution. It is not part of any BSD-licensed project.

Licence and the offer of source

The full licence text is in COPYING. These artifacts are an unmodified build of SDCC 4.5.0. The complete corresponding source is the upstream release tarball:

https://sourceforge.net/projects/sdcc/files/sdcc/4.5.0/sdcc-src-4.5.0.tar.bz2/download
SHA-256  d5030437fb436bb1d93a8dbdbfb46baaa60613318f4fb3f5871d72815d1eed80

No patches were applied to SDCC itself. One build-environment patch was needed for Emscripten, a libiberty psignal conflict. The build recipe, toolchain versions and link flags are in BUILD-INFO.md.

As GPL-2 section 3 requires, the publisher offers to provide the complete corresponding machine-readable source on request, for no more than the cost of performing distribution. Open an issue to take up that offer.

Served with Access-Control-Allow-Origin: *, so a browser on another origin may fetch and instantiate them directly.

The linking exception covers output, not redistribution

Each header under include/mcs51/ carries the GPL plus SDCC's linking exception, so a program compiled with this toolchain does not inherit GPL obligations from it. That exception is about the compiler's output. It says nothing about redistributing the compiler, which is why this repository is separate.
